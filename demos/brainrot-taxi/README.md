# My Brainrot Taxi Demo

This demo is based on the "my brainrot taxi" idea from the root README and consumes the framework as a Wally dependency.

## What This Demo Shows

- package consumption through `lluxy8/brainrot-framework`
- framework runtime bootstrapped through mounted framework folders in `ServerScriptService` and `StarterPlayerScripts`
- framework interactions wired to in-world `ProximityPrompt` stations
- client HUD updates from framework player attributes (`Brainrot_Coins`, task reward data)
- dynamic guide arrows rendered from player to the next station objective

## Run The Demo

1. Open a terminal in `demos/brainrot-taxi`.
2. Install dependency package:
   - `wally install`
3. Sync the installed package into a stable Rojo path:
   - PowerShell: `./scripts/sync-framework-package.ps1`
   - bash: `./scripts/sync-framework-package.sh`
4. Start Rojo:
   - `rojo serve default.project.json`
5. In Roblox Studio, connect with Rojo and play.
6. Use the two prompt stations:
   - `Wash Taxi` -> `WashCarInteract`
   - `Drop Passenger` -> `ServeCustomerInteract`

## Implementation Notes

- `default.project.json` mounts framework runtime trees from a stable folder:
  - `Packages/brainrot-framework-current` (generated by sync script)
  - `ReplicatedStorage.BrainrotFramework` -> `brainrot-framework-current/src/Shared`
  - `ServerScriptService.BrainrotFrameworkServer` -> `brainrot-framework-current/src/Server` subfolders (`Bootstrap`, `Components`, `Controllers`, `Services`)
  - `StarterPlayerScripts.BrainrotFrameworkClient` -> local framework `src/Client` subfolders (includes unreleased guide system)
- The demo scripts bootstrap via `RegisterServices/RegisterComponents` and `RegisterControllers` directly.
- The client script binds prompt instances to framework interaction IDs through `InteractionPromptComponent`.

## Version Bump Note

- When you bump `brainrot-framework` version in `wally.toml`, you only need:
  1. `wally install`
  2. `./scripts/sync-framework-package.ps1` (or `.sh`)
- No `default.project.json` path edits are needed.

## Troubleshooting

- If framework instances are missing, run `wally install` again inside `demos/brainrot-taxi` and restart `rojo serve`.
